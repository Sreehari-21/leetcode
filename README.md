## 🧠 Learning Philosophy

Every problem in this repository is approached methodically rather than memorized:

1. **Understand the problem**: Read constraints, clarify inputs/outputs, and outline edge cases.
2. **Develop brute-force solution**: Build an intuitive, working baseline to guarantee understanding.
3. **Analyze complexity**: Calculate theoretical time and space bounds ($O$ notation).
4. **Identify optimization**: Look for bottlenecks, redundant computations, or applicable data structures (e.g., hash maps, pointers, heaps).
5. **Implement optimized solution**: Write clean, PEP 8-compliant, interview-ready Python code.
6. **Re-solve without looking at the solution**: Reinforce retention and muscle memory.
7. **Record the underlying pattern**: Document transferable insights in [`notes/patterns.md`](notes/patterns.md).
